# THIRD-PARTY PLACEHOLDER. THIS NEVER SHIPS.

Anything in this folder is a DEVELOPMENT STAND-IN by someone else. It exists so
the code lanes (wrist slot, rope anchor, animation, textures) have a real mesh to
bind to while our own art is made.

## It cannot reach a release, and that is mechanical, not a promise

- `ArtSource/` is not cooked into any package. Verified 2026-08-15: all four
  archives contain Binaries, Content, Resources and the `.uplugin` only.
- `package_fpm.py` FAILS on any dev-only path, tested in both directions.

So this folder cannot ship by accident. Do not defeat either of those.

## Why the guard exists

Placeholders become permanent. That is the normal outcome, not the unlucky one.
FPM is GPL-3.0 and publicly released on ficsit.app, so a third-party asset here
would need redistribution AND modification AND commercial rights to ship, and
most free models grant none of them. A use-only licence is fine for THIS folder
and fatal one folder over.

## Required for every file placed here

| field | why |
|---|---|
| source URL | so the licence can be re-checked later |
| author | credit, if it ever becomes shippable |
| licence, quoted | "free to download" is not "free to redistribute" |
| date recorded | licences change |
| what replaces it | the exit plan, written down at the time |

An entry with no licence line is not a record. Absence of a licence is not
permission, even for local use.
